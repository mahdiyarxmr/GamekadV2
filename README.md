# گیم‌کاد (Gamekad) / اکوسیستم رُکاد

> **باشگاه بازی و رویدادهای حضوری در مشهد (هنرستان استارتاپی رُکاد)**  
> طراحی شده بر اساس **دستورالعمل زبان طراحی رُکاد (نسخه ۲.۰.۰ - Refined Neo-Brutalism)**  
> پیاده‌سازی کامل استک: **Node.js · NestJS · React + Vite · TypeScript · PostgreSQL + Prisma**

---

## 🎯 معرفی پلتفرم

پلتفرم گیم‌کاد سامانه‌ای جامع و تعاملی برای باشگاه رویدادها و بازی‌های حضوری رُکاد در مشهد است؛ محیطی برای شبیه‌سازی استراتژی، ارتقای مهارت‌های مذاکره و کارآفرینی و شب‌های مافیا.

### کاربران دمو جهت آزمون سریع (Quick Demo Login):
| نقش | نام کاربری | رمز عبور | دسترسی‌ها |
|---|---|---|---|
| **مدیر کل (Admin)** | `admin` | `admin123` | پنل کامل مدیریت `/admin`، میزبانی و خدای بازی، کنترل کاربران و کیف پول |
| **میزبان (خدای بازی)** | `host` | `host-pass-9` | میز زنده خدای بازی `/host/god-game`، پخش نقش‌ها، تایمر نطق |

| **هنرجوی رُکاد (دختر)** | `sara_art` | `player-pass-9` | نشان رسمی رُکاد، میزهای دخترانه |

## 🎨 زبان طراحی و سیستم بصری (Rokad Design System v2.0.0)

این پروژه با وفاداری کامل به مرجع طراحی رُکاد توسعه یافته است:
- **نئوبروتالیسم اصلاح‌شده (Refined Neo-Brutalism):** خطوط محیطی صریح (`1.5px`)، سایه‌های سخت فیزیکی زاویه‌دار بدون بلور (`shadow-hard-md: 2.75px 2.75px 0`), فرورفتگی لمسی دکمه‌ها در کلیک (`.btn-tactile`).
- **موتور چندپرسونایی (Persona Themes):**
  - 🌿 **اکوسیستم (Ecosystem):** سبز مینت `#59BBAF`
  - 🔵 **پسرانه (Male):** سرمه‌ای عمیق `#202A5A`
  - 🌸 **دخترانه (Female):** سرخابی `#E0195B`
  - 🟠 **کالج (College):** کهربایی مهارتی `#F8A41D`
  - 🟣 **باشگاه (Club):** بنفش نوآوری `#8A38F5`
- **حالت شب و روز (Dark / Light Mode):** پشتیبانی کامل در تمام صفحات.
- **تایپوگرافی فارسی RTL:** اعداد ذاتی فارسی (`۰۱۲۳۴۵۶۷۸۹`) و رعایت اصل **عدم گزافه‌گویی و حذف زیرمتن‌های اضافه (Zero Redundant Subtext)**.

## 🚀 قابلیت‌های پیاده‌سازی‌شده

### ۱. وب‌سایت عمومی (Public Pages)
- **صفحه اصلی (`/`):** بلوک‌های قابل جابجایی و تنظیم توسط ادمین (سرصفحه، رویداد ویژه، میزهای پیش‌رو، بازی‌ها، آموزش سناریو، لیدربورد، منتخبان MVP، مقالات و درباره باشگاه).
- **میزهای رویداد (`/events` و `/events/:id`):** فیلتر جنسیت (پسران، دختران، مختلط)، ظرفیت صندلی‌های باقی‌مانده، مدل‌های پرداخت (`full` آنلاین کامل، `deposit` پیش‌پرداخت، `venue` پرداخت در سالن)، سیستم هولد ۱۵ دقیقه‌ای و رزرو ۱ تا ۴ صندلی.
- **کاتالوگ بازی‌ها (`/games` و `/games/electronic`):** رومیزی (مافیا، شطرنج) و کنسولی (فوتبال PS5).
- **آموزش و کارت‌های نقش ۳ بعدی (`/guide` و `/guide/scenarios/:slug`):** سناریوهای کلاسیک، کاپو، نماینده، بازپرس و اکوسیستم کسب‌وکار به همراه **کارت‌های نقش با افکت چرخش ۳ بعدی (3D Flip Role Cards)**.
- **لیدربورد سروری (`/leaderboard`):** مرتب‌سازی دقیق سمت سرور (امتیاز نزولی → برد نزولی → شناسه صعودی)، فیلتر دسته‌بندی و تفکیک جنسیتی.
- **پروفایل بازیکنان (`/players/:username`):** عکس بزرگ، بیوگرافی، نشان رسمی رُکاد، **نمودار راداری عنکبوتی (Spider Chart)** بدون تداخل برچسب‌ها، کلکسیون مدال‌ها، دفتر عملکرد نقش‌ها و تاریخچه بازی‌های اخیر.
- **آموزش و مقالات (`/learn`):** مقالات آموزشی و اخبار بدون کامنت (طبق الزامات).

### ۲. سیستم مالی و کیف پول (Wallet & Finance)
- موجودی عدد صحیح **تومان**.
- شارژ دستی دلخواه + میانبرهای ۵۰، ۱۰۰، ۲۰۰ و ۵۰۰ هزار تومان.
- **قانون طلایی:** در صورت کفایت موجودی، کسر مستقیم از کیف؛ در غیر این صورت انتقال به درگاه سندباکس (عدم ترکیب دو روش).
- درگاه شبیه‌ساز سندباکس با کد پیگیری و تأیید قطعی سرور.
- دفتر کل ثبت تمام تراکنش‌ها (`WalletTransaction`).
- امکان تعدیل مالی توسط ادمین با ثبت علت در لاگ حسابرسی.

### ۳. میز خدای بازی (God Game / Game Master Console)
- مسیر: `/host/god-game` (مخصوص میزبان یا ادمین).
- ساخت نشست با سناریو و تعداد صندلی ۴ تا ۲۴ نفر.
- **پخش تصادفی نقش‌ها** با پنجره تأیید.
- **تایمر نطق و فازهای بازی (۳:۰۰ دقیقه)** با امکان توقف و بازنشانی.
- وضعیت هر صندلی: وضعیت زنده/مرده (با برچسب «مرده»)، اخطارهای انضباطی، اخراج با پنجره هشدار قرمز، نامزدی در رأی‌گیری و شمارنده آرا.
- ثبت لحظه‌ای لاگ وقایع و امکان درج یادداشت دستی.
- **ثبت پایان بازی و ایمپورت امتیازات به لیدربورد** (یک‌بار در طول بازی).

### ۴. پنل مدیریت ادمین (`/admin/*`)
- **داشبورد:** شاخص‌های KPI (بازیکنان، نشست‌های پیش‌رو، رزروهای پرداختی، درآمد و آموزش‌ها).
- **چینش خانه:** مدیریت بالا/پایین بردن بلوک‌ها و مخفی‌سازی با دکمه بازنشانی پیش‌فرض.
- **مدیریت رویدادها:** ایجاد نشست، مشاهده ثبت‌نام‌ها و دکمه ثبت حضور شرکت‌کنندگان.
- **مدیریت کاربران:** جستجو، تغییر نقش، اعطا/لغو مجوز خدای بازی، تعلیق و تغییر عضویت رُکاد/خارجی.
- **تعدیل کیف پول:** اعمال بستانکاری/بدهکاری با ثبت لاگ حسابرسی.
- **تنظیمات سامانه:** تغییر آدرس، تلفن و ساعات کاری باشگاه.

## 🛠 معماری و ساختار پروژه

```
gamekad/
├── server/                      # بک‌اند NestJS (TypeScript + Prisma)
│   ├── prisma/
│   │   └── schema.prisma        # اسکیما کامل PostgreSQL
│   ├── src/
│   │   ├── admin/               # ماژول پنل ادمین
│   │   ├── articles/            # مقالات و آموزش
│   │   ├── auth/                # ماژول احراز هویت JWT و گاردها
│   │   ├── common/              # دکوراتورها و گاردهای نقش و خدای بازی
│   │   ├── database/            # پایگاه داده و بارگذاری سید اولیه
│   │   ├── events/              # رویدادها و میزهای بازی
│   │   ├── games/               # بازی‌ها و سناریوها
│   │   ├── god-game/            # میز زنده خدای بازی
│   │   ├── homepage/            # داده‌ها و چینش خانه
│   │   ├── leaderboard/         # لیدربورد، بازیکنان و نمودار عنکبوتی
│   │   ├── reservations/        # رزرو صندلی و پرداخت
│   │   └── wallet/              # کیف پول و درگاه سندباکس
│   └── dist/
├── client/                      # فرانت‌اند React + Vite (TypeScript + Tailwind CSS)
│   ├── src/
│   │   ├── api/                 # کلاینت ارتباط با API (/api/v1)
│   │   ├── components/
│   │   │   ├── layout/          # Navbar, Footer, MobileTabBar, AdminLayout
│   │   │   └── ui/              # Button, Input, Modal, Badge, SpiderChart, FlipRoleCard, CountdownTimer, StatCard
│   │   ├── context/             # AuthContext, ThemeContext
│   │   ├── pages/               # تمام صفحات عمومی، کاربری، خدای بازی و ادمین
│   │   └── utils/               # فرمت‌کننده‌های اعداد فارسی و تاریخ شمسی
├── docker-compose.yml           # کانتینر PostgreSQL جهت محیط پروداکشن
└── package.json                 # اسکریپت‌های ریشه مونو‌ریپو
```

## ⚡ نحوه اجرا و راه‌اندازی

### ۱. اجرای هم‌زمان کلاینت و سرور:
```bash
# نصب پکیج‌ها (در صورت نیاز)
pnpm install

# اجرای هم‌زمان فرانت‌اند و بک‌اند
pnpm dev
```

- وب‌سایت فرانت‌اند: `http://localhost:5173`
- مستندات API سوآگر: `http://localhost:3000/api/docs`

### ۲. اجرای پایگاه داده PostgreSQL با داکر (اختیاری):
```bash
docker-compose up -d
```
> *نکته:* سیستم دارای موتور داده‌ای پشتیبان خودکار است و بدون نیاز به راه‌اندازی داکر یا سرویس خارجی نیز بلافاصله با تمام دیتای سید به کار خود ادامه می‌دهد.
